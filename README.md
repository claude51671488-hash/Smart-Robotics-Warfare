Текущая разработка 0.54.6: «Колокол» и одобренная цилиндрическая [«Матрёшка» V4](docs/MATRYOSHKA.md). Исправлены наведение, выбор целей и поза раскрытия под EMP. Добавлены нативная пробная проверка возможности выстрела и журнал этапов доставки. Последняя проверка в Forts ещё нужна; [проверки исходников](docs/SOURCE_CHECKS.md) её не заменяют. Бункер и плавная 48-кадровая походка Dynamit Bot приняты автором. Цикл шага ускорен вдвое без изменения скорости перемещения. Анимация перезарядки бункера отключена по окончательному решению автора.

## Проверка в Forts

1. Перезапустить игру. Начать НОВЫЙ тестовый бой с локальным модом, не со старой Workshop-копией. Временно отключить другие моды.
2. Построить Мастерскую, затем обычный Завод (технологию factory).
3. В устройствах выбрать «Наземная фабрика роботов I» с иконкой шахты. Установить на землю рядом с фортом; руда не требуется. Временная модель — шахта. Цена фабрики: 300 металла, 2000 энергии; строительство 15 с; здоровье 1000.
4. Слева должен быть заголовок «SRW 0.2.5 — Фабрика роботов» ещё до строительства. После завершения фабрики автоматически появятся состояние и две текстовые кнопки. Выделять фабрику не нужно. Проверить, что вторую построить нельзя, а после уничтожения первой строительство снова доступно.
5. Заказать бота. При начале производства списываются 200 металла и 2000 энергии. Через 7 с бот попадает в резерв. Без ресурсов заказ ждёт без списания.
6. Нажать «Выпустить одного робота». Временный корпус — небольшая бочка, 4000 HP. Она движется по земле к противнику, останавливается перед обрывом. Для первого теста нужна ровная земля перед выходом фабрики.
7. Проверить взрыв при приближении к вражескому устройству или контакте с вражеской балкой. Других Dynamit Bot он не выбирает целью. Уничтоженный бот тоже взрывается.

Резерв: 20 на фабрику. Очередь ожидающих: до 20. Активных ботов: до 10 на игровой teamId (в обычном бою — игрок), суммарно по фабрикам. Неудачный выпуск сохраняет резерв. Уничтожение фабрики уничтожает её очередь и резерв. EMP приостанавливает производство и движение. Автовыпуска и отмены заказов пока нет.

## Ограничения

- Броня, порог пробития и послойный взрыв ещё НЕ реализованы. Используется обычный взрыв Forts: 1200 по конструкции, 2000 по устройствам, радиус 318.75 единицы. Это радиальный урон движка, а не гарантированные 2000 каждому роботу.
- Нет анимации ног. Движение кинематическое, только по земле: без маршрутов через мосты, прыжков и полноценного обхода устройств. Перед крутым уступом бот стоит.
- «Шахта» временно равна 127.5 игровых единиц (ширина выделения стандартной шахты). Скорость 318.75 единиц/с. Дистанция подрыва выбирается при выпуске.
- Сторона 1 движется вправо, сторона 2 — влево. Нестандартные карты пока не поддержаны.
- Защита союзников от штатного взрыва не гарантирована, проверять отдельно.
- Игровой запуск новой версии, сетевой бой и повторы ещё требуют ручной проверки.

## Структура

- devices/ — фабрика и временный корпус.
- scripts/factories/production.lua — очередь, ресурсы, резерв.
- scripts/robots/movement.lua — выпуск и движение.
- scripts/ui/factory.lua — локальный интерфейс.
- scripts/config.lua — характеристики.
- mods/language-Russian и mods/language-English — названия объектов.

Состояние хранится в data.srw. UI отправляет команды через SendScriptEvent. Новые материалы и снаряды пока не добавлены.

## Проверки и установка

Команда: python tests/check_prototype.py

Проверка использует Lupa в соседней папке .srw-tools, вне мода. Проверяются синтаксис (с нормализацией расширения Forts для широких строк) и логика с подставными функциями движка. Это не игровой интеграционный тест.

В Forts/data/mods/SmartRoboticsWarfare копируются игровые файлы и ресурсы, без .git, docs, tests и инструментов. publishedfileid.lua, itemversion.lua и обложка существующей публикации сохраняются. Обновление Workshop выполняется вручную через Forts → Мастерская → Выложить. В эту сессию публикация не обновлялась.
