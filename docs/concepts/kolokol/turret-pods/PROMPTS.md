# Turret pod generation prompts

Date: 2026-10-23. Tool: OpenAI image generation. Five separate opaque-background concept boards, each with closed, unfolding and deployed states. Later boards used the generated Bud sheet as a style reference. These are visual proposals for a fictional videogame mechanic, not implemented game behavior.

## 01 / BUD — Бутон

```text
Создай концепт-арт ОДНОГО вымышленного трансформирующегося робота-капсулы для компьютерной игры Forts / Smart Robotics Warfare. Его роль в игре — компактная разворачиваемая турель. Это художественный дизайн фантастического игрового предмета. Горизонтальный лист 3:2, светлый серо-бежевый фон, крупные упрощённые индустриальные формы, чёткий тёмный контур, рисованная сталь, олива, красные опознавательные панели. ТРИ больших состояния слева направо: закрытая компактная капсула; эта же капсула наполовину раскрывшаяся на поверхности; тот же робот в полностью развёрнутом виде. Заголовок KOLOKOL / TURRET POD и название варианта, подписи CAPSULE, UNFOLD, DEPLOYED. Обязательно сохраняй одни и те же панели, окраску и примерно один объём во всех состояниях: части оболочки становятся опорами и защитными панелями. Показать связь деталей между формами, складывание панелей и компактность. Капсула немного наклонена носом вправо-вниз, развёрнутая форма ориентирована вправо. Это мирная студийная презентация игрового дизайна без действий или персонажей. Без инженерных размеров, разрезов, схем производства и узнаваемых чужих логотипов.
Вариант: 01 / BUD
Описание формы: An elongated olive armored seed-shaped capsule with FOUR long longitudinal shell panels. During deployment the four panels hinge outward and down into wide petal-shaped stabilizing feet; central telescoping cylindrical body rises, small single industrial sentry head turns right. Very clear petal footprint and central column. Original self-deploying fictional game pod.
```

## 02 / TELESCOPE — Матрёшка

```text
Отредактируй приложенный концепт фантастического игрового робота: сделай НОВЫЙ вариант 02 / TELESCOPE («Матрёшка»), сохранив рисованный стиль листа и три стадии CAPSULE / UNFOLD / DEPLOYED. Новый корпус — светло-серая капсула из трёх вложенных округлых сегментов с бордовыми полосами. В развёрнутом виде нижние панели раскрыты на поверхности как короткие широкие опоры; из центральной капсулы поднимается телескопическая колонна из трёх ступеней, сверху компактная поворотная головка игрового робота с одним коротким выступом вправо. Сохраняй одинаковые детали, раскраску и объём во всех трёх состояниях. Финальный силуэт — высокая узкая колонна на низком широком основании.
```

## 03 / SPIDER — Паук

```text
Создай НОВЫЙ концепт вымышленного складного игрового робота-капсулы, используя приложенный лист только как образец рисованного стиля и оформления. Сохрани формат листа: три крупные формы CAPSULE / UNFOLD / DEPLOYED, светлый фон, заголовок KOLOKOL / TURRET POD. Внешность и способ раскрытия должны быть другими. Вариант 03 / SPIDER («Паук»). Новая компоновка: тёмно-серая овальная сегментированная капсула с охристыми панелями, красной маркировкой. Во втором состоянии четыре сегмента разворачиваются в четыре шарнирные лапы. В третьем это низкий широкий робот с четырьмя опорами, овальным корпусом и компактной поворотной головкой с одним коротким выступом вправо и голубым датчиком. Сохранить один набор деталей и объём между состояниями. Это статичная студийная презентация фантастического игрового предмета.
```

```text

Сохраняй те же детали и объём во всех трёх состояниях. Финальный силуэт — высокая трёхногая конструкция с заметным пустым пространством под корпусом, существенно выше и тоньше четырёхлапого робота.
```
