# Matryoshka V2 generation prompts

Date: 2026-10-23. Tool: OpenAI image generation. The concept uses the original Matryoshka as a form reference and Bastion V3 as the style reference. The animation layer atlas is generated from the new olive concept. This is a proposed art revision, not a production sprite or implemented game mechanic.

## Concept

```text
Перерисуй первый приложенный концепт игрового турельного снаряда «Матрёшка» в художественном стиле второго изображения «Колокол». Это фантастический предмет для 2D-игры Forts. Материалы и палитра второго изображения: потёртая оливковая краска, тёмная сталь, грубые броневые накладки, крупные болты и красная маркировка. Сохрани последовательность трёх состояний: компактная закрытая капсула; оболочка раскрывается и её панели становятся опорами; вложенные секции выдвигаются и поднимают поворотную головку турели. Из небольшой капсулы должна механически вырастать более высокая турель из тех же деталей. Покажи промежуточное раскладывание панелей, а не только замену готовых форм. Нейтральный светлый фон, тот же рисованный игровой стиль, подписи CAPSULE / UNFOLD / DEPLOYED. Заголовок KOLOKOL / MATRYOSHKA. Без персонажей, выстрелов, попаданий и боевой сцены.
```

## Transparent animation layer atlas

```text
Подготовь отдельные рисованные детали для GIF-анимации ПРИЛОЖЕННОЙ оливковой «Матрёшки». Сохраняй её внешний вид: потёртая олива, тёмная сталь, крупные болты, красные плоские панели. PNG с прозрачным фоном, горизонтальный лист 3:2, строго сетка 4 столбца × 2 ряда, без текста и линий сетки. Восемь изолированных деталей по центрам ячеек, с широкими прозрачными промежутками. В верхнем ряду слева направо: 1 целая закрытая компактная капсула вертикально носом вниз; 2 отдельная левая длинная панель оболочки с шарниром у нижнего конца; 3 отдельная правая зеркальная панель; 4 отдельная задняя короткая опорная панель. В нижнем ряду слева направо: 5 низкий круглый воротник основания центральной стойки; 6 нижняя широкая цилиндрическая секция стойки; 7 верхняя узкая цилиндрическая секция стойки; 8 компактная бронированная поворотная головка с прежним коротким выступом вправо. Не рисуй фон и тени на фоне. Все детали должны соответствовать приложенному оливковому варианту и позволять собрать его обратно. Вместо красного светящегося глаза на головке сделай обычную тёмную металлическую крышку. Только отдельные части фантастического игрового предмета для художественной анимации, без действия.
```
