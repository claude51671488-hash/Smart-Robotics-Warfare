# Орудия бункера — текущее решение 22 октября 2026

Башни неподвижны. Head (UserData=50) вращает только ствол; Barrel (UserData=100)
даёт нативный откат. Root (UserData=0) содержит бронекожух. Root.Pivot компенсирует
масштаб изображения, обе стороны имеют зеркальные определения.

По последней просьбе автора перезарядка полностью статична: нет Loader,
Chamber, подачи снаряда и выброса гильз. В Sprites нет ссылок на кадры загрузки.
Сам таймер перезарядки и пулемётная очередь сохранены.

Пушка −3…+7°, пулемёт −7…+20°. Скорость 12500/6500 сохраняет прежнюю дальность
настильного огня при ограниченном угле. Низкая траектория рассчитывается явно,
без случайного разброса. У пули нет сопротивления воздуха; визуально она штатная.
Пушка сохраняет выбранный медный снаряд и сплеш 300 в радиусе 350, прямой урон 700.
Пулемёт имеет удвоенный штатный урон. Оригинальные боеприпасы игры не изменяются.

Периодические круг и отдельная мишень принадлежали локальному Native Probe.
Автоматические появления удалены, круг бункерного взрыва отключён. Нативный
визуальный эффект самого попадания сохранён вместе с реальным взрывным уроном.

Авторские изображения деталей ранее созданы встроенным ImageGen. Техническая
сборка — tests/export-bunker-rig.ps1. Локальные исходники/промпты находятся
в art-source/engineering-rig/ и не входят в публичный Git. Этот старый экспортёр
сохраняет исторические кадры подачи, но игра больше на них не ссылается.

Актуальные результаты проверки — DEVELOPMENT_STATUS.md.
