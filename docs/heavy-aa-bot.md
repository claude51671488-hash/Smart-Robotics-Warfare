# Страж III — 0.17.0

Фабрика III → редактор отряда → страница 3 → «+ Страж III».
Одна дальнобойная зенитная пушка, без личного купола. 2400 HP, скорость
1.1 шахты/с, дальность 4500, выстрел каждые 0.35 с, скорость пули 12000,
AntiAirDamage=100. Урон задаётся снарядом движка; автоматического удаления
цели при выстреле нет. Производство 24 с, 800 металла / 6500 энергии,
лимит 2, интервал выпуска следующего робота 8 с. Баланс временный.

Цели: вражеские снаряды впереди и выше корпуса, доступные для перехвата.
Сначала приближающиеся, среди них — с большей суммой прямого и взрывного
урона; затем расстояние и ID. Упреждение предполагает постоянную скорость,
поэтому маневрирующие ракеты могут уйти от выстрела. EMP снижает точность.

Без целей сопровождает боевых роботов. Другие зенитчики, ремонтники и
щитоносцы не используются как ведущие. Наземные устройства не атакует.
Воздушные роботы-устройства пока не являются целями: этот этап будет добавлен
вместе с воздушными роботами. Пока Страж — усиленный перехватчик снарядов.
