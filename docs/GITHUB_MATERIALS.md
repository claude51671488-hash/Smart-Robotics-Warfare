# Материалы в GitHub

23 октября 2026 года выполнена первая полная загрузка доступных рабочих
материалов в два подготовленных репозитория, без изменения их видимости.

- Публичный `claude51671488-hash/Smart-Robotics-Warfare`: код нашего мода,
  используемые игровые текстуры, тесты и документация. Существующие удалённые
  концепты «Колокола» и «Матрёшки» сохранены. Импорт: `364a32a`.
- Приватный `claude51671488-hash/Forts-Reference-Sources`: распакованные
  справочные файлы Forts, сторонние моды и их текстуры, скачанные бесплатные
  материалы с сопроводительными лицензиями, исходные концепты и присланные
  Krita-файлы. Импорт: `967ac74`; 29 441 файл, 1 300 535 885 байт исходных
  данных. `INVENTORY.json` хранит размеры и SHA-256 каждого файла импорта.
  Ранее загруженные справочные файлы также сохранены.

Исполняемые файлы, DLL, игровые .pack-архивы, видео, журналы, резервные копии,
секреты и Workshop metadata не загружались. Не все упакованные игровые ресурсы
доступны в виде распакованных исходников: архив не следует считать полной
резервной копией установленной игры.

Рабочая папка SmartRoboticsWarfare теперь следует чистой публичной истории.
Старая локальная история, содержавшая справочные материалы, сохранена отдельно
в локальном .srw-tools/srw-before-clean-import.bundle и не опубликована.
Не отправлять этот bundle и старую историю в публичный репозиторий.

Подготовленный клон приватного архива расположен в соседнем
`.srw-tools/reference-upload`. При последующих синхронизациях сначала получать
удалённые изменения и проверять Private. Пользовательские материалы из других
папок не добавлять без явной связи с проектом. Обновления текущего кода мода
сохранять из основной рабочей папки обычными коммитами, без force push.
