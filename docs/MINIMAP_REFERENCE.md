# Миникарта фабрики

Изучен установленный мод Minimap / Миникарта, Workshop 3269866418:
https://steamcommunity.com/sharedfiles/filedetails/?id=3269866418

Он создаёт AddSpriteControl для маркеров, обновляет координаты устройств,
сохраняет пропорции карты и отдельно отображает область камеры.
Из его textures/ball1.png и ball2.png взяты два маркера по просьбе пользователя
использовать добавленный мод как пример. Они включены как map_ally.png и
map_enemy.png; сам мод миникарты не является зависимостью SRW.

В SRW используется своё преобразование в координаты окна фабрики.
Границы определяются фабрикой, союзными роботами и реакторами обеих сторон,
а не искусственно расширенным GetWorldExtents. Отступы сохраняют читаемость,
границы расширяются при выходе робота за край и не сжимаются при потерях.
Синие маркеры — союзные корневые роботы; красные — вражеские реакторы.
Орудия одного робота не добавляют лишних маркеров. Модифицированные реакторы
распознаются также по GetDeviceCanClaimStructures. Обновление 5 раз в секунду,
только при открытом окне. Это схема расположения объектов, без изображения
рельефа и без рамки камеры. Все данные и графика локальны.
