## Работа с телефона

Открыть репозиторий в браузере GitHub или подключить его к облачной задаче Codex.
Для продолжения дать задаче ссылку на этот файл и конкретное изменение. Коммиты
позволяют продолжать работу между устройствами; запуск Forts остаётся на Windows.
Чат автоматически в Git не переносится: ключевые решения должны оставаться в docs/.
