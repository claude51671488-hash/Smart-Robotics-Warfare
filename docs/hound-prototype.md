# Гончая — 0.4.0

Первый вооружённый наземный робот. Временный корпус — уменьшенная штатная пушка;
пулемёт и независимые оружейные модули пока не добавлены.

После завершения фабрики справа от кнопок Dynamit Bot доступны заказ и выпуск
«Гончей». Hound в счётчике: резерв / очередь / активные. Общий резерв фабрики — 20,
ожидающая очередь — 20 суммарно. Производится один робот за раз; при наличии обеих
очередей типы чередуются. У подрывника и «Гончей» отдельные лимиты по 10 активных.

Временные параметры: 200 металла, 2000 энергии, 7 с производства; 1200 HP;
скорость 2 шахты/с; дальность поиска 1400; перезарядка 2 с; прямой урон 100.
Баланс, броня, конечная графика и второй ствол не настроены.

Гончая идёт по земле, ищет вражеские устройства впереди, отдавая приоритет типам
роботов нашего мода. Останавливается при выборе доступной для наведения цели,
использует штатную стрельбу и перезарядку. При потере цели продолжает движение.
EMP останавливает движение и стрельбу. Полноценного обхода препятствий нет.

Снаряд — отдельная копия штатного cannon с изменёнными характеристиками; ванильный
боеприпас не меняется. Остальные унаследованные свойства ещё требуют проверки.
Урон по роботам пока обычный, без новой системы брони.

Проверки: tests/check_hound.py (включает регрессии подрывника), tests/check_shields.py.
Моделируются производство, общий резерв, владение, ошибка выпуска, выбор цели,
остановка при стрельбе и EMP. Нативная стрельба и наведение проверяются в Forts.

В новом бою проверить обе стороны карты: выпуск, движение, остановку перед врагом,
попадания, перезарядку и продолжение движения после уничтожения цели. Если робот
останавливается без выстрела, в журнале будет строка Hound ... fire result=...
