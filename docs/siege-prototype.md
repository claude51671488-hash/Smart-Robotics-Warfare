# Осадный робот — прототип 0.7.0

Одна мортира, фугасная мина Колокола: 135 прямого / 270 взрывного урона,
радиус взрыва 180. Наведение 45–85 градусов, перезарядка 8 с.
Временные характеристики: 900 HP, скорость 1.2 шахты/с, поиск цели до 5000,
минимальная дистанция 500. Предпочитает устройства и оружие противника роботам.
Голые балки пока не являются самостоятельными целями; попадают под снаряды
на пути к устройству. Баллистическое решение проверяется через AimWeapon.

Останавливается для стрельбы. При противнике впереди ближе 500 отступает,
если позади есть земля и нет преграды. Без решения для стрельбы продвигается.
Не обходит сложные препятствия; движущиеся цели не сопровождает с упреждением.
Поддерживается ремонтником, EMP блокирует движение и огонь.

Для тестирования доступен на текущей фабрике: четвёртая строка заказа/выпуска.
300 металла / 2500 энергии / 12 с; максимум 5 на игрока. Общие очередь и резерв
остаются по 20. Окончательный тир пока не назначен.
Корпус от штатной мортиры, кнопки kega.png.

Проверить в новом матче: производство, навесную траекторию и реальный урон,
остановку на дистанции, отступление при сближении, совместную работу с Гончей
и ремонтником, показ всех кнопок фабрики. Python-тесты заменяют API и не
подтверждают баллистику в самом движке.
