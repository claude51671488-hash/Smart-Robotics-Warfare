# Гром III — 0.18.0

Фабрика III → редактор отряда → страница 3 → «+ Гром III».
Тяжёлый артиллерийский робот с одной мортирой без личного щита.
Предпочитает устройства форта, затем роботов. Голые балки не выбирает целью.
Минимальная дистанция 1000, дальность поиска 7000. Действительная возможность
попадания зависит от высоты, препятствий и решения штатного AimWeapon.
При противнике ближе минимальной дистанции впереди прекращает стрельбу
и пытается отступить; перед обрывом или препятствием останавливается.

Временные параметры: 2200 HP, скорость 0.7 шахты/с, перезарядка 12 с,
скорость мины до 5500. Мина: 200 прямого + 650 взрывного урона, радиус 300.
Производство 35 с, 1100 металла / 9000 энергии, лимит 2, выпуск через 8 с.
Взрыв штатный: послойный урон пока не реализован. Снаряд перехватывается
куполами SRW по общим правилам. Новый EMP ухудшает точность, штатный —
полностью отключает корпус. Временный корпус — мортира, иконки — kega.png.

check_heavy_siege.py проверяет уровень фабрики, производство/выпуск,
дальность, отступление, обрыв, EMP, союзников и параметры мины.
Это проверки с заглушками. Реальную траекторию, попадания и отступление
нужно проверить в новом матче Forts.
