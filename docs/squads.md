# Отряды — 0.10.0

Выбрать свою фабрику → «Создать отряд». Кнопки слева добавляют робота;
кнопка минус удаляет последнее вхождение этого типа. Порядок добавления
определяет порядок изготовления и выхода.

Справа:
- «Сохранить отряд»: сохранить один шаблон состава для своего владельца в матче.
- «Загрузить состав»: восстановить шаблон в редактор.
- «В производство»: поставить копию состава после уже существующих одиночных заказов.
- «Очистить состав»: очистить только редактор; оплаченный/готовый отряд не удаляется.
- «Выпустить отряд»: после полной готовности начать последовательный выпуск одной кнопкой.

Готовность: количество изготовленных роботов, процент выполненного времени,
примерное оставшееся рабочее время, число вышедших и таймер выхода. Оценка
учитывает стоящие впереди одиночные заказы. Время ожидания ресурсов, EMP и
перестройки заранее неизвестно: во время таких пауз счётчик не отсчитывает
предполагаемое календарное время до готовности. Указание причины — строка статуса.

Готовый отряд занимает общий резерв по одному месту на робота. Его состав
отделён от одиночных резервов: ручной выпуск не может забрать его участника.
При запуске проверяется место под весь состав и предыдущие заказы. Роботы
оплачиваются по одному при начале изготовления, без повторного списания
при выпуске или повторном нажатии кнопки запуска.

Прототип хранит один активный отряд на фабрику. Пока он не выпущен целиком,
новый отряд и новые одиночные заказы не принимаются. Редактор можно менять
и сохранять независимо. Число одного типа в составе ограничено его активным
лимитом; уже находящиеся на карте роботы могут временно задержать выпуск.

Каждый успешно вышедший робот задаёт фабрике ExitRemaining из своего ExitDelay
в scripts/config.lua. У всех текущих прототипов 3 секунды; будущему титану
можно назначить 8. Общий таймер действует и на ручной, и на отрядный выпуск.
Интервал обеспечивает разницу во времени выхода, а не гарантированный зазор
при остановке роботов у выхода. Позиционное разведение неподвижных роботов
пока не реализовано. Порядок «боевые → поддержка» подходит текущему ИИ сопровождения.

При неудачном создании участник остаётся в резерве; повторная попытка через
0.5 с. При лимите активных роботов выпуск ждёт освобождения места. EMP или
улучшение фабрики приостанавливают выпуск. Состояние отряда, редактор и таймер
переносятся при улучшении I → II → III. При уничтожении фабрики её отряд теряется.

Шаблон хранится в data.srw.SquadTemplates: переживает уничтожение фабрики
и сохраняется вместе с матчем. Это не библиотека между разными матчами.

Проверка в игре: собрать Гончая → осадный → ремонтник → ПВО, сохранить,
очистить и загрузить; изготовить, проверить занятость резерва, затем выпустить
одной кнопкой. Проверить интервалы, недостаток ресурсов, улучшение с текущим
заказом и сохранение/загрузку. Python-тесты не заменяют проверку UI и сети Forts.
