# Проверки исходников

Для Python-проверок нужны lupa и Pillow. По умолчанию тесты наследования ищут
данные установленной Forts в стандартном пути Steam. Для другого расположения
указать папку data с оригинальными определениями игры через FORTS_DATA_ROOT.
Подменять их заглушками для получения успешного результата нельзя.

```bash
export FORTS_DATA_ROOT=/path/to/Forts/data
python tests/run_checks.py --jobs 4 \
  --exclude check_deployment.py --exclude check_engineer.py \
  --report tests/last-validation.json
```

Две исключённые проверки сохраняются без ослабления: check_deployment.py запускает
локальный PowerShell-установщик для Windows, check_engineer.py дополнительно
читает авторские .kra по локальному пути. На авторском ПК полный набор запускается
через `python tests/run_checks.py`. Исключения выводятся отдельно и не считаются
успешными тестами. Ни один из этих запусков не заменяет свежий процесс Forts.
Не помещать оригинальные данные игры или отчёты с локальными путями в публичный Git.

Для проверки изображений нужен Pillow. Если основной Python не имеет Pillow,
задайте SRW_ART_PYTHON абсолютным путём к отдельному Python с этой библиотекой.
Проверка слоёв запустится в нём; отсутствие библиотеки без этого параметра — ошибка,
а не пропуск или успешная проверка. Полный локальный набор теперь 68 проверок.
