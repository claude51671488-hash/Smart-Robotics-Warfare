# Охотник II — 0.15.0

Фабрика II–III → «Создать отряд» → страница 2 → «+ Охотник II».
Редактор теперь показывает по пять типов на странице. Кнопка «1 / 2 >»
переключает страницу без изменения состава и очереди.

Охотник предпочитает вражеских роботов, затем устройства форта. Идёт вперёд,
останавливается для стрельбы, выпускает шесть снарядов с интервалом 0.1 с.
Фиксирует положение на 0.8 с, чтобы не двигаться во время очереди.
Это наступающий противороботный юнит; отдельного режима охраны или выбора
сопровождаемой артиллерии пока нет. Цели позади пока не выбираются.

Временные параметры: 1400 HP, скорость 2.4 шахты/с, дальность 2400,
65 прямого урона за попадание без взрывного урона, перезарядка 1.5 с после
очереди. ИИ начинает очереди с интервалом не менее 2.2 с.
Производство 12 с, 350 металла / 3000 энергии, лимит 5, выпуск через 3 с.
Точность снижается новым EMP, штатный EMP отключает корпус полностью.

Временный корпус — штатный пулемёт, иконки — kega.png. Особой системы брони
и отдельного множителя урона по роботам пока нет. Купола используют обычный
перехват снарядов. Проверки check_hunter.py и check_squads.py выполняются
с заглушками: реальную очередь, попадания и обе страницы проверить в Forts.
