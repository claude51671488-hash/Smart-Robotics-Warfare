# Проверка 0.5.1

- Колокол: MaxFireSpeed 2750 → 3900, остальные настройки баллистики сохранены.
  При одинаковой высоте и угле это примерно удвоение максимальной дальности.
- Гончая: поиск цели 1400 → 2800, предел орудия 1600 → 3200.
  Исправлен Gravity; контактный снаряд 100 прямого + 80 взрывного урона,
  радиус 80, без штатной таблицы отражения cannon и мгновенного уничтожения щита.
  Это изменение прототипа, а не подтверждённый диагноз нулевого урона в игре.
- Фабрика отображается только при выборе своей фабрики. Снятие выбора скрывает
  все её элементы; повторный выбор открывает панель.
- Купол: заголовок/статус y=180/220, кнопки y=265/311 вместо 465/511.
- Отрисовка активной дуги: 16 сегментов при 10 Гц вместо 64 при 20 Гц.
  Геометрия перехвата сохраняет 64 сегмента. Время жизни визуальных линий 0.12 с.
- Балки считываются один раз на сторону за обновление роботов, без хранения
  между обновлениями: движущиеся машины остаются актуальными.
- Далёкие снаряды отсекаются до проверки сегментов щита; история хранит только
  текущие снаряды. Убран двойной вызов обновления UI и спам штатной перезарядки.
- Раз в 60 игровых секунд журнал содержит счётчики SRW health.

Все Python-проверки прошли, включая 10000 обновлений обработки щита.
Это проверки с заменителями API, а не длительный игровой матч.
Доступный журнал предыдущего сбоя был перезаписан запуском игры; причина вылета
не установлена. При повторении сохранить log.txt до следующего запуска Forts.
