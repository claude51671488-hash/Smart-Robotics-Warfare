# Посылка I — 0.48

Пятый воздушный робот первого уровня, концепт № 24. Несёт одну тяжёлую бомбу, рассчитывает точку сброса с учётом скорости цели и своего движения, затем возвращается к воздушной фабрике. Повторное вооружение занимает 8 секунд возле работающей фабрики; в полёте заряд не восстанавливается. Если родная фабрика уничтожена, выбирает другую союзную воздушную фабрику. Если её нет, ожидает у прежней базы.

Доступны одиночное производство, резерв и отряды. Индекс 28 сохраняет прежнюю нумерацию. EMP останавливает аппарат и обслуживание; отключённая фабрика не выдаёт новую бомбу. Неудавшееся создание снаряда не расходует заряд.

| Параметр | Прототип |
|---|---:|
| Прочность | 1000 |
| Скорость одиночного аппарата | 3 ширины шахты/с |
| Дальность поиска цели | 16000 единиц движка |
| Металл / энергия | 500 / 4500 |
| Производство | 22 с |
| Интервал выпуска | 3 с |
| Прямой / фугасный урон бомбы | 1350 / 1800 |
| Радиус взрыва | 550 единиц движка |

Корпус пока использует временную модель; бомба — авторскую текстуру снаряда. Полёт без отдельной аэродинамической модели. Точные пределы поражения движущихся целей требуют дальнейших боёв: прогноз предполагает постоянную скорость цели на время падения.

## Проверка

53 автоматических набора проверок прошли, LuaPlus разобрал 140 Lua-файлов. Проверены производство, списание ресурсов, резерв, два цикла сброса/обслуживания, упреждение движущейся цели, EMP, потеря и замена фабрики, отказ создания снаряда.

В свежем процессе Forts два аппарата с противоположных сторон выполнили по три сброса: 6 бомб, 6 попаданий по вражеским тестовым целям, два повторных вооружения на аппарат. Самопопаданий не зарегистрировано, здоровье обоих аппаратов осталось полным. Сценарий завершился на кадре 2600; после очистки счётчики роботов, модулей и отслеживаемых снарядов равны нулю.

Для проверки возврата в этой нативной сцене использованы прочные диагностические опоры, которые тестовый адаптер представляет воздушными фабриками. Производство через настоящую фабричную логику и её потеря проверены автоматическими сценариями; этот опыт не является полной проверкой пользовательского интерфейса фабрики или длительного массового боя.

Результаты: `tests/native-air-048-results.json`, журнал: `tests/native-air-048-runtime.log`. Ошибок Lua в проверке не найдено; в полном журнале запуска присутствуют два сообщения LIBCURL об отсутствии загружаемого файла, отдельно сохранённые в сводке.

Все пять воздушных концептов первого уровня имеют прототипы. Следующий — Архангел II; вместе с ним необходим второй уровень воздушной фабрики.
