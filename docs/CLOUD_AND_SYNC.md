# Облачная работа и локальная копия

Публичный мод: https://github.com/claude51671488-hash/Smart-Robotics-Warfare

Приватные справочные исходники: https://github.com/claude51671488-hash/Forts-Reference-Sources

Локальные автоматизации этого чата работают только когда компьютер включён и
Codex запущен. Они не превращают локальную задачу в облачную. Для работы при
выключенном ПК нужна отдельная облачная среда/задача, которой доступны эти
репозитории. Сам GitHub хранит код, но не запускает разработку Codex.

В облаке начать с AGENTS.md и docs/DEVELOPMENT_STATUS.md. Оригинальные исходники
и сторонние моды не копировать в публичную историю. Сохранять изменения обычными
коммитами; не считать облачный тест доказательством работоспособности Forts.

На компьютере tests/sync-from-github.ps1 получает обновления только через fast
forward. При локальных правках, ошибке доступа или расхождении веток он
останавливается и сохраняет работу. Скрипт подготовлен; автоматический запуск
при входе в Windows ещё не установлен. Установка ресурсов в Forts — отдельный
шаг через install-local.ps1 при закрытой игре.
